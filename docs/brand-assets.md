# Brand assets

## Originals (authoritative, read-only)

| File                                                | Size           | Use                                      |
| --------------------------------------------------- | -------------- | ---------------------------------------- |
| `assets/brand/latansa-logo-horizontal-original.png` | 4500×4500 RGBA | Navbar, compact headers                  |
| `assets/brand/latansa-logo-vertical-original.png`   | 4500×4500 RGBA | Selected corporate-identity compositions |

Both are the official 21 January 2025 final logo files supplied by the client. Only these repo
files are used as sources — not copies elsewhere on disk, and not other LATANSA repositories
(which contain a different, unofficial mark).

**Missing:** a vector source (SVG, AI, EPS or PDF). The PNGs are high-resolution, so raster
derivatives are sharp at every size the site needs. If the client has the vector file, add it
as `assets/brand/latansa-logo-*-original.svg` — do not trace or recreate the logo.

## Derivatives

Generated by `npm run brand:assets` ([scripts/brand-assets.mjs](../scripts/brand-assets.mjs)):

| Output                                                           | Notes                                                |
| ---------------------------------------------------------------- | ---------------------------------------------------- |
| `public/brand/latansa-logo-horizontal-{480,960,1440}.{png,webp}` | Transparent padding trimmed                          |
| `public/brand/latansa-logo-vertical-{480,960}.{png,webp}`        | Transparent padding trimmed                          |
| `public/brand/latansa-symbol-{256,512}.{png,webp}`               | Symbol cropped from the horizontal lock-up           |
| `src/app/icon.png` (512), `src/app/favicon.ico` (16/32/48)       | Symbol on transparent square                         |
| `src/app/apple-icon.png` (180)                                   | Symbol on a white square (iOS shows no transparency) |
| `src/config/brand-assets.json`                                   | Intrinsic sizes for `<BrandLogo>`                    |

Allowed operations: trim transparent padding, proportional resize, format conversion, cropping
the symbol out of the lock-up, placing it on a square canvas. **Not allowed:** recoloring,
filters, redrawing, changing proportions or spacing, adding effects.

## Usage

Use `<BrandLogo variant="horizontal|vertical|symbol" />` from
`src/components/brand/brand-logo.tsx`. Size by width with `h-auto`.

- Place the full-color logo on light surfaces only (white, or cloud `#F4F6F8`). In the approved
  direction it appears on white, in the header and the footer.
- No monochrome or reversed treatment is needed, because the approved direction never places the
  logo on a dark surface. Any future derivative must keep the exact geometry and needs the owner's
  approval before use.
- Minimum navbar width ≈ 140px at 360px viewports so the subtitle stays legible.
